# План разработки

## Реализовано

- Русскоязычное окно Qt Widgets с пакетным добавлением, видимой очередью, фильтром библиотеки, отменой, повтором и просмотром результатов.
- Импорт видео, аудио, TXT, DOCX, SRT, VTT и JSON. Локальное распознавание faster-whisper по ограниченным фрагментам, VAD, временные метки и контрольные точки.
- Полная расшифровка Word и сопутствующие TXT, JSON, SRT. Академическое оформление A4 и Times New Roman. При сбое облачного анализа локальная расшифровка доступна из очереди.
- Бесплатный облачный анализ по согласию пользователя. Проверка каталога перед генерацией, лимиты цены, кеш блоков, обработка 429, сверка цитат. Конспект и задания сохраняются отдельными документами.
- Хранение ключа OpenRouter в Windows Credential Manager. Сетевые пути Windows и фоновое наблюдение за одной папкой с проверкой стабильности файлов. Наблюдение добавляет задания в локальном режиме.
- Проигрыватель с переходами к фрагментам расшифровки. Проверка GitHub Releases, проверка хеша установщика и запуск после подтверждения. Портативная сборка обновляется вручную.
- Сценарии PyInstaller, Inno Setup, контрольные суммы и GitHub Actions. Автопубликация запускается тегом соответствующей версии после проверок.

- В версии 0.2.0 добавлены локальный отбор кадров и OCR, Word со слайдами, список заданий с таймкодами и проверка говорящих с ручным назначением ролей.
- В интерфейс подключён адаптер Community-1 при наличии совместимого окружения. Подтверждённые роли сохраняются отдельно от полной расшифровки.
- Текст кадров может участвовать в облачном анализе при отдельном согласии. Документ задания сохраняет тип источника и проверяет цитаты и озвученный срок.
- В настройках доступны сведения об оборудовании. Автоматический режим может повторить распознавание на CPU при ошибке ускорения.

- В ветке 0.3.0 добавлены установка из локальной папки выпуска, повторная проверка установщика перед запуском, четыре шаблона Word и редактируемые формулы OMML для поддерживаемого TeX.

- В 0.4.0 добавлены встроенная ONNX-диаризация, выбор вероятного преподавателя, проверка ключа и экспорт журнала TXT. Обновление GitHub загружается без выбора папки.

- В 0.4.1 добавлены удаление строки с исключением из наблюдения за папкой, предварительная проверка папки вывода, ранний выбор CPU в автоматическом режиме при недоступной CUDA и обработка голосов до восьми часов блоками.
- В установленной 0.4.1 воспроизведён сбой Whisper на CPU. В диагностической Windows-сборке выявлена несовместимая DLL OpenSSL из System32. Замена пары DLL на файлы из комплекта Python позволила Whisper обработать тот же ролик и сообщить об отсутствии речи. В 0.4.2 сборщик закрепляет происхождение DLL и проверяет создание контекста TLS. Журнал фиксирует этапы и безопасные сведения об ошибках.

## Проверено локально

- Windows x64, Python 3.12, короткий синтетический русскоязычный MP4, FFmpeg/FFprobe и Whisper base на CPU. Экспорт DOCX, JSON, SRT, временные метки и повторное открытие результата.
- Локальная очередь, импорт и экспорт, восстановление, фоновое наблюдение и облачный клиент в автоматических тестах. OpenRouter имитирован для запросов генерации.
- Прервано и возобновлено распознавание 61-минутной синтетической записи из 13 блоков. Whisper нашёл русские фрагменты в начале и после отметки 01:01:00.
- Восьмичасовой синтетический файл с длительной паузой обработан локально на CPU. Проверены реплики в начале и в конце, последние временные метки и DOCX.
- Проверено воспроизведение H.264 и переход к фрагменту по отметке. Независимо проверен снимок главного окна 1080 × 660.
- Адаптер диаризации pyannote Community-1 проверен с имитацией модели. Реальная модель и пользовательский сценарий пока не проверены.

- На предоставленной 15-минутной записи автоматически отобраны 10 кадров. Tesseract 5.5.3 распознал русский текст на слайде с требованием подготовить конспект на 10 страниц. Запись обработана локально.
- Проверен переход на CPU при отсутствии cuBLAS на машине с RTX 3060 Ti. Распознавание на CUDA до установки совместимых DLL недоступно.

## Оставшиеся этапы

- Улучшить качество разделения голосов на совещаниях и лекциях. Доработать исправление меток отдельных реплик и проверить сопоставление голосов на реальной многочасовой записи.
- Расширить конвертацию формул из неструктурированного текста и слайдов. Добавить произвольные пользовательские стили Word.
- Доработать многошаговый мастер, менеджер загрузки моделей, профили обработки, системный трей и настройки облачного анализа.
- Разделить промпты для очистки, конспекта, заданий, слайдов, формул и отдельной проверки результатов. Добавить итоговое сведение конспекта и тесты качества на реальных записях.
- Проверить реальный OpenRouter с ключом, введённым в интерфейсе, естественную лекцию до 8 часов, CUDA, Windows Credential Manager, обновление и SMB на Synology.
- Выпуск 0.4.0 опубликован после проверки CI и комплектования лицензий. Обновление с 0.3.0 проверено с живым GitHub на чистом Windows-раннере. Для следующей версии повторить проверку и ревью.
