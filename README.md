# Учёба AI

Приложение Windows для подготовки учебных документов из видеозаписей и готовых расшифровок. Локальный режим сохраняет расшифровку в Word, TXT, JSON и SRT при наличии временных меток. По отдельному согласию выбранная расшифровка отправляется в OpenRouter для создания конспекта и списка заданий.

## Запуск из исходников

В PowerShell с Python 3.12 x64:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m ucheba
```

Для аудио и видео нужны FFmpeg и FFprobe в PATH или рядом с собранным приложением. При первом использовании faster-whisper загружает выбранную модель. Для запуска на CPU начните с модели small. Ключ OpenRouter вводится в интерфейсе и сохраняется в диспетчере учётных данных Windows.

## Результаты

Каждое задание публикует свою папку. Откройте её из библиотеки. Если приложение закрылось во время распознавания, очередь продолжит обработку с последнего сохранённого фрагмента при доступности исходного файла. Для сетевых папок укажите доступный Windows UNC-путь.

Цитаты из заданий сверяйте с записью по временным меткам. Сгенерированный план выполнения помечается отдельно от требований преподавателя.

## Настройка OpenRouter

Для облачного анализа используйте ключ рабочей области OpenRouter без подключённых ключей сторонних провайдеров (BYOK). OpenRouter может отправить запрос через такой ключ, и провайдер выставит счёт отдельно. Приложение ограничивает цены маршрутизации OpenRouter нулём. [Правила BYOK в OpenRouter](https://openrouter.ai/docs/guides/overview/auth/byok)

## Сборка Windows

Используйте Python 3.12 x64. После активации окружения установите зависимости сборки командой `python -m pip install -e ".[dev,build]"` и запустите `./scripts/build-windows.ps1`. Файлы установщика, портативный ZIP и SHA-256 создаются в `release`. Приложение и установщик не подписаны, поэтому Windows может показать предупреждение SmartScreen.

Данные очереди и настройки хранятся в профиле Windows. Портативная версия запускается из распакованной папки и использует тот же профиль. Флаг `-TestInstaller` проверяет установку и удаление в чистом тестовом профиле.

## Говорящие

При добавлении аудио или видео включено автоматическое разделение говорящих. Локальная модель анализирует голоса, а приложение предлагает кандидата по продолжительности и репликам с указаниями. Если уверенности недостаточно, кандидат не назначается. После обработки откройте «Говорящие», послушайте образцы и подтвердите роли. Готовится отдельный DOCX с репликами вероятного преподавателя, а исходная расшифровка остаётся доступна. Встроенная модель принимает записи длительностью до восьми часов. Записи длиннее часа делятся на 15-минутные блоки. При неоднозначности голосу назначается отдельная метка.

В локальном комплекте обе модели приложены. В сборке GitHub модель голосовых признаков загружается на устройство при первом использовании и проверяется по SHA-256. Через Интернет передаётся только запрос на загрузку модели. Для повторного анализа с подтверждёнными ролями добавьте `Расшифровка_с_подтверждёнными_ролями.json` как новое задание.

Дополнительный адаптер Community-1 доступен при запуске из исходников с отдельной установкой pyannote. [Страница модели](https://huggingface.co/pyannote/speaker-diarization-community-1)

## Слайды и OCR

При добавлении видео включите извлечение слайдов. Результат содержит отдельный DOCX с кадрами, таймкодами и распознанным текстом. Для OCR нужен Tesseract с языками `rus` и `eng` в PATH или в стандартной папке Program Files. Если Tesseract не запускается из пути с кириллицей, используйте путь к программе с латинскими символами. Само видео и папка результатов могут иметь русские имена. Без Tesseract сохраняются изображения. На кадрах захвата рабочего стола может быть текст соседних окон. [Установка Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html)

Для работы на NVIDIA также нужны совместимые библиотеки CUDA 12 и cuDNN 9 в среде приложения. В автоматическом режиме приложение пробует CPU, когда запуск ускорения завершается ошибкой.

## Обновление из приложения

В установленной версии откройте «Обновления» и нажмите «Обновить из GitHub…». Приложение найдёт новый стабильный выпуск, загрузит EXE, сверит версию, SHA-256 и состояние Authenticode. Перед запуском установщика проверка повторится. Подтвердите установку после завершения текущей обработки. Папку для загрузки выбирать не нужно. Локальный комплект с EXE и SHA256SUMS.txt также поддерживается.

Для неподписанного установщика SHA-256 проверяет целостность. Получайте оба файла из доверенного источника. Портативная версия устанавливается распаковкой нового архива в отдельную папку. Профиль Windows сохраняется в обоих случаях. Обновление со старой версии, в которой ещё нет выбора локальной папки, выполняется однократным запуском нового EXE.

## Шаблоны Word и формулы

При добавлении лекции выберите один из четырёх шаблонов Word. Поддерживаемые формулы, явно выделенные синтаксисом TeX, экспортируются в редактируемом формате Word OMML. Другие конструкции сохраняются как исходный текст.

## Проверка ключа и технический журнал

Рядом с полем OpenRouter в настройках нажмите «Проверить ключ». Можно проверить новый ключ из поля или уже сохранённый ключ. Запрос генерации не отправляется. Остаток бесплатного лимита показывается, когда OpenRouter сообщает его.

В главном окне нажмите «Журнал TXT…» и выберите место сохранения. Экспорт содержит версию программы, платформу, этапы обработки, типы ошибок и доступные числовые коды Windows и HTTP. Ключи, текст лекций, локальные пути и имена файлов не включаются.

## Удаление записи

Выберите строку и нажмите «Удалить из списка…». Кнопка доступна после завершения или отмены фоновой обработки. Команда убирает запись из очереди и библиотеки. Исходный файл и готовые документы сохраняются. Если файл находится в наблюдаемой папке, приложение не добавит его снова автоматически. Ручное добавление остаётся доступным.
