# Сборка Windows x64

На Windows 11 с Python 3.12 x64 и PowerShell 7 из корня репозитория:

```powershell
py -3.12 -m venv .venv
. ./.venv/Scripts/Activate.ps1
python -m pip install ".[dev,build]"
./scripts/build-windows.ps1
```

Сборка закрепляет версию и SHA-256 архива FFmpeg. Если компилятор
Inno Setup уже установлен, скрипт использует его. Иначе скрипт скачивает
Inno Setup 6.7.4, проверяет подпись Pyrsys B.V. и ставит компилятор
в каталог сборки для текущего пользователя. Для явного выбора компилятора
передайте его полный путь через `-Iscc`.

В каталоге `release` появятся `UchebaAI-Setup-x64.exe`,
`UchebaAI-Portable-x64.zip` и `SHA256SUMS.txt`. Модель распознавания
загружается при работе приложения. Для ZIP распакуйте все файлы, включая
подкаталог `_internal`, и запустите `UchebaAI.exe`. Портативный запуск
сохраняет пользовательские данные в обычном профиле Windows.

Скрипт проверяет запуск замороженного приложения и обе утилиты FFmpeg.
Ключ `-TestInstaller` дополнительно устанавливает программу во временный
каталог, проверяет запуск и удаляет тестовую установку. Используйте его в
тестовом профиле Windows или на CI.

Сборки без сертификата Authenticode могут вызывать предупреждение
Windows SmartScreen. Сверьте SHA-256 скачанного файла с `SHA256SUMS.txt`
из того же официального выпуска. При установке и удалении пользовательские
настройки и документы остаются в исходных каталогах.

Ручной запуск workflow «Публикация Windows x64» требует выбора
существующего тега `vMAJOR.MINOR.PATCH`. Он должен совпадать с версией в
`pyproject.toml`, для которой существует раздел в `CHANGELOG.md`.
Workflow публикует файлы только после успешной сборки, тестов и аудита
зависимостей.
