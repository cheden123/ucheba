# Архитектура

- Qt Widgets отвечает за настройки, управление заданиями и статус. Рабочий поток выполняет задания последовательно, а SQLite хранит очередь между запусками. Блокировка Qt удерживается на время работы приложения.
- FFprobe получает длительность, FFmpeg извлекает ограниченные по длине WAV-фрагменты, faster-whisper распознаёт их с VAD. Контрольные точки привязаны к источнику и настройкам распознавания.
- Передача текста в OpenRouter включается для конкретного задания. Запросы используют ценовые ограничения и сверяют доказательства с исходными сегментами.
- DOCX и сопутствующие файлы записываются во временную папку на том же томе, затем публикуются переименованием. Идентификатор задания позволяет повторно открыть опубликованный результат после сбоя между публикацией и записью в SQLite.
